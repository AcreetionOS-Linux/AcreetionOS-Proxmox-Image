Archmox Backup Server

Enterprise-grade, content-addressable backup for VMs and containers, written in Rust and packaged for Arch Linux. Deduplicated, encrypted, and verifiable.

Install PBS Read the Docs
Overview

Backups you can trust

Archmox Backup Server (PBS) is an enterprise-grade backup solution for VMs and containers featuring content-addressable storage, inline deduplication, and encryption. The core is written in Rust for maximum performance.

PBS integrates natively with PVE and supports backing up to local storage, NFS, SMB, and S3-compatible object storage.

Capabilities

Key features

Content-Addressable Storage

Data is chunked and indexed by cryptographic hash, eliminating duplicates.

Inline Deduplication

Identical data blocks are stored once, dramatically reducing storage usage.

Client-Side Encryption

Encrypt backups before they ever leave the source.

Incremental Backups

Only changed blocks are transferred after the initial full backup.

Scheduling & Retention

Configurable schedules with prune policies (keep-last, keep-daily, and more).

Remote Sync

Sync backups between PBS instances for off-site disaster recovery.

Web UI & REST API

A full management interface plus an automation-ready API.

Verification Jobs

Automatically verify backup integrity on a schedule.

Packages

What gets installed

PBS is composed of these core PKGBUILD packages:

  • archmox-pbs — Backup server daemon and tools
  • pxar — High-performance archive format
  • archmox-pbs-qemu — QEMU integration for live VM backups
