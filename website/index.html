About the project

Virtualization, the Arch way

Archmox is an open-source virtualization stack for Arch Linux, sponsored by the AcreetionOS Project. It builds on a stable, LTS-focused base with the Arch Linux LTS kernel carrying the required patches, then packages the entire virtualization stack as native Arch Linux packages.

Every component is maintained as a PKGBUILD, installed and updated with pacman, and managed with systemd — no Debian packaging, no foreign dependency trees. Archmox is a community-built project maintained by Natalie Cole-Clift Spiva and contributors.

# /etc/pacman.conf
[archmox]
SigLevel = Required DatabaseOptional
Server = https://cdn.archmox.acreetionos.org/$repo/$arch

# Refresh databases and install
sudo pacman -Sy archmox-proxmox-ve

Component packages such as archmox-pbs and pmg-api can be installed individually. Installation media is coming soon — see the CDN for details.

Contribute

Archmox is community-driven and we welcome pull requests on GitHub. Priority areas:

  • Porting Perl modules from Debian paths to Arch paths
  • Converting debian/rules to PKGBUILDs
  • Adapting the installer for archiso
  • Testing on bare metal and writing documentation

Security

Report vulnerabilities to security@archmox.acreetionos.org. Please encrypt sensitive reports using our GPG key.
